# WarPlanet

Пошаговая стратегия про захват провинций для Android — телефонов и планшетов. В партии до 8 игроков: двое живых на двух телефонах в одной Wi‑Fi сети и до 6 ИИ‑соперников. Сервер и интернет не нужны.

## Что есть в игре

- Две карты на выбор перед игрой (против ИИ, вдвоём на телефоне и по Wi‑Fi):
  - **Европа** с Кавказом и Ближним Востоком: 88 провинций суши, 55 морских зон, 12 стартовых столиц;
  - **Африка**: каждая страна — одна клетка (50 стран), вокруг только океан — ни Европы, ни Аравии; 70 морских зон, 11 стартовых столиц.
- Армии — отряды солдатиков в цвете страны, флоты — корабли, над ними плашка с числом.
- Провинции с населением, доходом и счастьем; налог 0–90%, очки действия (ОД, бывают с половинкой).
- Несчастные провинции (счастье ниже 40%) могут восстать и стать ничейными.
- Туман войны: чужие армии видно только в 2 клетках от своей земли и своих армий.
- Найм войск, укрепление (1.5 ОД и 30 золота, оборона ×2), покупка нейтральных провинций, мародёрство, праздник (+счастье).
- Война объявляется явно; одновременные ходы с конфликтами; бой со случайностью ±5%, бои показываются после хода.
- ИИ‑соперники трёх уровней сложности, до 6 в партии.
- Условия победы: превосходство (порог 50–95%), доминирование, уничтожение, захват флага; лимит ходов.
- Игра вдвоём по Wi‑Fi (один телефон — хост), игра против ИИ, режим «на одном телефоне».
- Сохранение после каждого хода и «Продолжить».

Во второй этап (не входит): туман войны, типы юнитов и эпохи, мир и союзы, режим «Защита», онлайн через Firebase.

## Как получить APK

### Вариант 1. GitHub Actions — без установки чего-либо

Каждый пуш запускает тесты и сборку (`.github/workflows/android.yml`). Готовый файл: вкладка **Actions** → последний запуск **Android APK** → артефакт **warplanet-apk** (zip с `app-release.apk`). Запуск можно сделать и вручную: **Run workflow**.

### Вариант 2. EAS (облачная сборка Expo)

```bash
npm install
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview      # APK для установки на телефоны
npx eas-cli@latest build -p android --profile development  # dev build, работает вместе с `npx expo start`
```

Профили описаны в `eas.json`. Expo Go не подходит: нужны нативные модули для сети.

### Вариант 3. Локально

Нужны Node.js 20+, JDK 17+ и Android SDK (проще всего — через Android Studio).

```bash
npm install
npx expo prebuild -p android
cd android
./gradlew assembleRelease
# APK: android/app/build/outputs/apk/release/app-release.apk
```

Или сразу на подключённый телефон: `npx expo run:android`.

### Подпись своим ключом

Без настроек release‑APK подписан стандартным отладочным ключом Android. Он публичный и одинаковый у всех, поэтому отдельные антивирусы на эвристиках помечают такие файлы как «потенциально нежелательные» (PUP). Подпишите APK своим ключом:

```bash
# один раз: создать ключ (храните файл и пароль — без них не выпустить обновление)
keytool -genkeypair -keystore warplanet-release.jks -storetype PKCS12 -alias warplanet \
  -keyalg RSA -keysize 4096 -validity 10000 -dname "CN=WarPlanet"
# подписать собранный APK
apksigner sign --ks warplanet-release.jks --ks-key-alias warplanet \
  --out WarPlanet.apk android/app/build/outputs/apk/release/app-release.apk
```

Для GitHub Actions добавьте в **Settings → Secrets and variables → Actions** секреты `ANDROID_KEYSTORE_BASE64` (файл ключа в base64: `base64 -w0 warplanet-release.jks`), `ANDROID_KEYSTORE_PASSWORD` и `ANDROID_KEY_ALIAS` — сборка будет подписываться автоматически. EAS создаёт и хранит ключ сам. Файлы ключей в репозиторий не кладутся (`*.jks` в `.gitignore`).

## Как играть вдвоём по Wi‑Fi

1. Оба телефона в одной Wi‑Fi сети.
2. Первый: **Создать игру** — откроется лобби с настройками, IP и портом.
3. Второй: **Найти игру** — игра появится в списке. Ищется двумя способами сразу: mDNS (`_conquest._tcp`) и перебором адресов своей Wi‑Fi подсети на порту игры (многие роутеры глушат mDNS); перебор идёт от соседних адресов, по два сразу, и полный проход занимает до минуты. Если не появилась — введите IP и порт из лобби хоста. Обе стороны должны стоять на одной версии игры.
4. Каждый нажимает на кольцо на карте, чтобы выбрать стартовую столицу. Хост нажимает **Начать**.

Ходы одновременные: каждый отдаёт приказы и жмёт **Готово**, хост считает ход за всех, включая ИИ. Если связь пропала, второй телефон переподключается сам и получает полное состояние; хост ждёт его до 2 минут, затем ставит паузу. Партия сохраняется на хосте после каждого хода.

## Правила перемещения и войны

- Каждое перемещение (приказ) стоит **0.5 ОД**. Повторный приказ туда же складывается и ОД не тратит.
- **По своей земле** армия идёт до **4 клеток** за ход и сразу оказывается на месте — это видно на карте ещё до «Готово». Пришедшие солдаты в этом ходу дальше не идут.
- **В чужую провинцию** — только в соседнюю с вашей землёй (можно пройти до неё по своей земле, всего не больше 4 шагов). Дальше по чужой территории — по одной провинции за ход. Армия встаёт у границы, бой — после «Готово».
- **Война.** В провинции другой страны нельзя войти, пока ей не объявлена война: тап по её провинции → **Объявить войну**. Объявить и напасть можно в одном ходу. У объявившего счастье во всех провинциях падает на 10%, у того, на кого напали, — нет; он может отвечать без объявления. Война длится до конца партии.
- **Флот.** Посадка на корабли (из прибрежной провинции в соседнее море) — **2 золота за солдата**. Флот проходит до **5 морских клеток**, высадка — последним шагом. Чужой флот не обойти; бой в море — с силой ×0,5.
- **Праздник** в своей провинции: +20% счастья за золото (население / 2000, не меньше 5) и 0.5 ОД.
- **Налог и счастье.** Налог 0–90%. Цель счастья круто падает с налогом: 30% → 81, 60% → 54, 90% → 19. Счастье растёт на 5 за ход, а падает на треть разрыва до цели.
- **Восстания.** При счастье ниже 40% каждый ход есть шанс восстания: 1.5% за каждый пункт ниже порога (при 30% — 15%, при 0% — 60%). Повстанцев — население / 700; они бьются с гарнизоном (укрепление помогает). Выстоял гарнизон — восстание подавлено. Нет — провинция становится ничейной, на ней армия повстанцев: её может захватить любой, кто её победит.
- **Туман войны.** Чужие армии и флоты видно только в 2 клетках (по суше и морю) от своих провинций и своих армий; остальная карта чуть темнее, но чьи там земли — видно.
- **Новости.** Если вам объявили войну или у вас было восстание, в начале хода появится сообщение с кнопкой «ОК».
- Порядок расчёта хода: доход и содержание → объявления войны → действия в провинциях → перемещения (мирные — первыми) → бои → рост и счастье → восстания. После расчёта бои с вашим участием показываются по очереди: армии сходятся, числа тают, виден итог. Кнопка **Пропустить** — сразу к журналу.

## Управление

- Прокрутка карты — пальцем, зум — двумя пальцами.
- Тап по своей провинции с армией — рядом с пальцем два квадрата: **город** (данные и действия: найм, укрепление, праздник, мародёрство) и **солдаты** (сразу отправка армии). Тап по другой провинции — её панель (покупка нейтральной, объявление войны).
- В режиме отправки подсвечиваются клетки, куда можно пойти; тап по ней — выбор числа солдат. То же — перетащить своих солдатиков пальцем. Если туда нельзя, вверху появится причина. Тап по своему флоту — сразу отправка флота, по морю — только подсветка.
- Налог — тап по значку налога в верхней панели.
- Кнопки внизу справа: «Отменить последний» и «Готово», рядом — готовность второго игрока. «Готово» видно, только когда не открыто ни одной панели или окна, и оно переспрашивает: «Завершить ход?» — Да / Нет.

## Структура кода

| Папка | Что внутри |
|---|---|
| `src/engine/` | Правила на чистом TypeScript, без React и сети: состояние, приказы, `resolveTurn(state, orders)`. Случайность — только из генератора с сидом партии |
| `src/engine/config.ts` | Все числа баланса из ТЗ — баланс подкручивается только здесь |
| `src/ai/` | ИИ‑соперники: `planOrders(state, playerId, difficulty)` |
| `src/net/` | Протокол (JSON по строкам: `hello`, `orders`, `state`, `ping`, `game_over`), хост, клиент, обнаружение |
| `src/game/` | Контроллер партии для всех режимов, сохранение |
| `src/ui/` | Экраны и отрисовка карты на Skia |
| `tools/maps/` | Скрипт сборки карт из Natural Earth в `assets/maps/*.json` |

Стек: Expo (React Native, TypeScript), `@shopify/react-native-skia`, `react-native-gesture-handler`, `react-native-reanimated`, `react-native-tcp-socket`, `react-native-zeroconf`, `@react-native-async-storage/async-storage`, `jest`.

## Разработка

```bash
npm install
npm test            # тесты движка, ИИ, карты и сети (по TCP на localhost)
npm run typecheck
npm run web         # браузерная версия для проверки интерфейса (без игры по сети)
npm start           # Metro для dev build на телефоне
```

### Карты

```bash
npm run maps        # node tools/maps/build.mjs europe && node tools/maps/build.mjs africa
```

Скрипт сам скачивает Natural Earth, по суше стран в `bbox` считает прямоугольник карты, берёт всю сушу стран из списка внутри него (без косого среза по меридиану; земля из `dropBackground`, например Северная Африка, становится морем), сливает регионы в провинции примерно равной площади (внутри страны), делит море на зоны диаграммой Вороного, упрощает контуры через mapshaper, считает соседство по общим границам и добавляет проливы (Босфор, Дарданеллы, Эресунн, Керченский, Бонифачо). Настройки карты — `tools/maps/configs/<id>.mjs`: страны, число провинций, затравки морских зон, проливы, стартовые столицы. В `africa.mjs` включены `onePerCountry` (страна — одна клетка, без разбиения), `nameBy: 'country'` (подписи — названия стран), `background: false` (чужой суши нет, вокруг вода) и азимутальная равновеликая проекция. Новая карта = новый файл настроек; движок от конкретной карты не зависит. Картинка для проверки — `tools/maps/out/<id>.svg`.

Чтобы провинций было ~90 при сохранении узнаваемых малых стран (Бельгия, Швейцария, страны Балкан — по одной провинции), вес страны при раздаче провинций учитывает площадь и немного население (`areaExponent`, `popExponent`). Внутри страны провинции примерно равны по площади. Крым выделен в отдельную нейтральную провинцию.

### Графика

Спрайты и иконки пока рисуются кодом в едином стиле. Чтобы заменить их картинками, положите PNG в `assets/sprites/` или `assets/ui/` с именами из `assets/LICENSES.md` и выполните `npm run assets`. Источник и лицензию каждого файла записывайте в `assets/LICENSES.md`.
